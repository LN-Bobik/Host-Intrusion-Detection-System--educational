# HIDS - Host Intrusion Detection System
    Демон для контроля целостности файлов в Linux. Отслеживает изменения в директории /etc, 
    вычисляет SHA-256 хэши, содержащихся там файлов, оповещает через syslog о нарушении (в случае несовпадения хэшей). 
    Остальные события (создание файлов, удаление и.т.д) также логируются. Проект представляет собой минимальную базу для построения hids

## Возможности
  - **Демонизация** - отвязка от терминала через fork(*2) + setsid
  - **Мониторинг** - отслеживание событий файловой системы через inotify
  - **Контроль целостности** - сравнение SHA-256 хэшей с эталонной базой
  - **Безопасное хранение** - baseline-база с правами 600 (только root)
  - **Защита от повторного запуска** - pid-файл с эксклюзивной блокировкой
  - **Управление сигналами** - SIGTERM (завершение), SIGHUP (перечитывание конфига), SIGUSR1 (принудительная  проверка)
  - **Логирование** - syslog с уровнями от DEBUG до ALERT

## Требования
- Система: Linux (Debian/Ubuntu);
- Компилятор: GCC или Clang;
- Для работы демона необходима установка/обновление криптографической библиотеки OpenSSl:
    
```bash
sudo apt install libssl-dev
```

## Сборка
  ```bash
  make
  ```

## Запуск (первый)
  ```bash
  sudo ./hids
  ```
## При последующих запусках выдача прав не требуется:
  ```bash
  ./hids
  ```
    
# Просмотр логов
## Debian/Ubuntu (rsyslog, рекомендуется при первом запуске):
  ```bash
  tail -f /var/log/syslog | grep hids
  ```
## Или через journalctl (если настроен):
  ```bash
  journalctl -t hids -f
  ```

## Остановка
  ```bash
  sudo pkill -TERM hids
  ```
    
# Принцип работы
  1. Загружается baseline-база (при первом запуске создаётся файл `/var/lib/hids/baseline.db` с правами 600)
  2. Устанавливается watch на `/etc` через inotify
  3. При событии `IN_CLOSE_WRITE` вычисляется текущий хэш
  4. Хэш сравнивается с эталоном
  5. При несовпадении — алерт в syslog

## Сигналы

  | Сигнал  | Команда                  | Действие                    |
  |---------|--------------------------|-----------------------------|
  | SIGTERM | `kill -TERM PID`         | Плавное завершение          |
  | SIGHUP  | `kill -1 PID`            | Перечитывание конфигурации  |
  | SIGUSR1 | `kill -10 PID`           | Принудительная проверка     |

## Безопасность
  baseline.db хранится с правами 600, а сам каталог /var/lib/hids/ имеет права 700, что является достаточным для учебной версии. 
  Файлы открываются с O_CLOEXEC, чтобы дочерние процессы не наследовали чувствительные данные. pid-файл защищён блокировкой fcntl, 
  при демонизации игнорируется SIGHUP для защиты от обрыва терминала.
